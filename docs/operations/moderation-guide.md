# 운영 제재 가이드 (2026-10-09)

관리자 페이지에서 신고를 처리하고 사용자를 제재할 때의 기준이다. 기획은 bredy_app `docs/prd/admin-moderation.md`, 화면은 `/admin/reports`·`/admin/users`·`/admin/users/[id]`·`/admin/posts`·`/admin/products`·`/admin/auctions` 다.

## 1. 원칙
- 신고가 들어왔다고 자동으로 제재하지 않는다. 운영자가 보고 고른다.
- 콘텐츠는 **숨김이 기본**이다. 숨김은 작성자에게만 보이고 되돌릴 수 있으며, 원문 스냅샷이 남는다.
- **삭제**는 남겨 두면 안 되는 경우만 쓴다: 개인정보 노출, 불법 촬영물·음란물, 법적 요청. 삭제는 되돌릴 수 없다(상품은 목록에서 내리고, 혈통은 회수한다).
- 모든 조치는 대상자에게 알림이 간다. 대상자에게는 **사유 범주와 운영자 메시지만** 보이고, 누가 신고했는지·신고 내용·내부 메모는 보이지 않는다.
- 신고자에게는 조치(숨김·삭제·경고·정지)가 적용됐을 때만 "조치했어요" 알림이 간다. 기각하거나 조치 없이 닫으면 알리지 않는다.

## 2. 권장 조치 사다리
최근 180일 동안 받은 경고·기간 정지 수를 센다. 화면의 "권장"은 이 표를 따른다. 자동으로 적용되지 않는다.

| 최근 180일 경고·정지 | 권장 조치 |
|---|---|
| 0 | 경고 |
| 1 | 3일 정지 |
| 2 | 10일 정지 |
| 3 | 30일 정지 |
| 4 이상 | 영구 정지 |

- 정지 기간은 1·3·7·10·30일 중에서 고른다.
- 이미 정지 중인 사용자에게 정지를 더 주면 **남은 기간에 더한다**(예: 2일 남았는데 3일 → 5일 뒤 해제).
- 영구 정지 계정에는 기간 정지를 줄 수 없다. 먼저 해제한다.
- 경고는 정지 중에도 줄 수 있다. 정지가 끝난 뒤 앱·웹에 들어오면 확인 모달로 보인다.

## 3. 사유 코드
| 코드 | 화면 문구 | 주로 쓰는 신고 사유 |
|---|---|---|
| SPAM | 스팸·광고 | 스팸·광고, 스팸 계정 |
| ABUSE | 욕설·비하·혐오 표현 | 욕설·비하·혐오 표현, 욕설·부적절 내용 |
| SEXUAL | 음란·선정적 내용 | 음란·선정적 내용, 음란 메시지 |
| PRIVACY | 개인정보 노출 | 개인정보 노출 |
| FALSE_INFO | 허위 정보 | 허위 정보 |
| FRAUD | 사기·허위 매물 | 허위 매물·사기 의심, 사기 의심, 사기 이력 의심 |
| ILLEGAL_ITEM | 거래 금지 품목(불법 개체) | 거래 금지 품목(불법 개체) |
| DUPLICATE | 중복·도배 | 중복·도배 게시 |
| HARASSMENT | 괴롭힘·협박 | 욕설·협박, 반복적 욕설·괴롭힘 |
| IMPERSONATION | 사칭 | 사칭, 남의 혈통 이름 도용 |
| TRADE_ABUSE | 거래 방해·비정상 거래 | 입찰 방해/분쟁 유도, 비정상 가격 유도(경매) |
| OTHER | 기타 | 기타 — 대상자에게 보낼 메시지 5자 이상 필수 |

신고 처리 패널은 신고 사유에서 이 코드를 기본값으로 고른다. 내용을 보고 바꿔도 된다.

## 4. 대상자에게 보낼 메시지 예시
- 경고(ABUSE): "댓글에서 다른 회원을 비하하는 표현이 확인되었어요. 서로 존중하는 표현을 부탁드려요."
- 3일 정지(SPAM): "같은 분양 글을 반복해서 올려 이용을 정지했어요."
- 영구 정지(FRAUD): "입금 후 개체를 보내지 않은 사기 신고가 여러 건 확인되어 이용을 영구 정지했어요."
- 기타(OTHER): 어떤 행동이 문제였는지 한두 문장으로 적는다. 신고자를 짐작할 수 있는 내용은 적지 않는다.

## 5. 신고 처리 순서(`/admin/reports`)
1. 신고 행에서 **처리하기**를 눌러 패널을 연다.
2. 콘텐츠 조치(없음·숨김·삭제)를 고른다. 채팅·사용자 신고는 콘텐츠 조치가 없다.
3. 피신고자 요약 줄(최근 180일 경고·정지·받은 신고)과 권장 조치를 보고 사용자 조치를 고른다.
4. 사유와 메시지를 확인하고, 미리보기 문구가 맞는지 본다.
5. 같은 대상의 열린 신고는 기본으로 함께 닫힌다(제재는 1건만 생긴다).
6. **처리** 또는 **기각**. 영구 정지는 `BAN`, 삭제는 `DELETE` 를 입력해야 실행된다.

동시에 다른 운영자가 같은 신고를 처리했으면 "이미 처리된 신고예요"가 뜬다. 목록을 새로고침한다.

## 6. 기록
- 사용자 제재: `UserSanction`(유형·사유·메시지·내부 메모·기간·운영자·관련 신고·확인 시각)
- 콘텐츠 조치: `ModerationLog`(숨김·해제·삭제, 사유 코드·메모·원문 스냅샷)
- 신고: `Report.contentAction`·`Report.sanctionId`(경매 신고는 `AuctionReport.sanctionId`)
- `/admin/users/[id]` 의 탭에서 제재 이력·받은 신고·콘텐츠 조치를 본다.

## 7. 권한
- 신고 처리·제재·숨김·삭제: 관리자(ADMIN·SUPER_USER·허용 목록 이메일).
- 역할 변경·다른 계정으로 로그인·계정 탈퇴 처리: 허용 목록(`libs/server/adminAccess.ts`)의 최고 관리자만.
